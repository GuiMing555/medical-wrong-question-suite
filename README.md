# 医学题库错题循环练习与导出工具

这个项目源于实际刷题时遇到的问题：一些已经购买的题库没有完善的错题重复练习逻辑，也不支持将错题导出保存。为了能够把遇到的问题题目留下来反复练习，并形成便于打印和复习的错题资料，开发了这套完全在本地运行的医学综合错题整理与练习工具。

项目由两个独立应用组成，共用同一个 SQLite 题库：

- **错题每日自动化整理**：截取指定窗口，使用 macOS Vision 识别文字，整理错题并生成可打印的 Word 文档。
- **医学综合练习**：提供普通练习和错题练习，逐题保存作答状态；中途退出时自动结束本轮练习。

目前 macOS 版本可以构建使用。Windows 迁移代码位于 `Windows/`，仍需在 Windows 环境完成构建和功能验证。

## 适用范围

当前版本主要围绕医学综合题目开发和测试，但识别、查重、导出及循环练习流程本身并不依赖特定医学知识。对于政治、法律等以固定选项的单选题、多选题和现成解析为主的科目，理论上也有适配的可能。

不同题库的页面版式、选项标记和解析结构可能存在差异，目前没有对这些科目及各类平台逐一验证，因此不能保证直接使用时都能正确识别；必要时可能需要针对具体版式调整解析规则。

## 主要功能

- 默认单独轻点右侧 Shift 截图，也可以在设置中更换快捷键。
- 可指定截图保存目录、文档输出目录和需要截取的窗口。
- 使用系统自带的 Vision 框架在本机识别截图，不上传图片。
- 每日定时整理错题，默认执行时间为 15:00。
- 分别生成纯题、答案与解析、薄弱知识点三份可打印 DOCX 文档。
- 自动按题干查重；连续截到同一道题视为误操作，不累计错误次数。
- 同一道题有时间间隔地重复出现时累计次数，达到 2 次后标红并显示计数。
- 无答案、无解析、选项不全或重复截图等记录会复制到待校对目录，并在文件名前注明原因。
- 截图整理工具和练习工具共用题库，识别出的完整题目可以直接进入练习应用；同步时只作为普通题导入，不会自动加入练习错题本。

## 练习模式

普通模式会选取从未作答或超过设定复习间隔的题目，并打乱题目和选项顺序。错题模式只练习当前错题；连续答对达到设定次数后，题目会自动移出错题本。

每次提交都会立即写入数据库。练习错题本只记录实际答错或点击“我不会”的题目，不会因为题目来自截图而自动加入。单选题选中正确答案后自动进入下一题；答错时显示解析。多选题需要手动提交，答错后停留在当前题。所有题型都提供独立的“我不会”选项，点击后直接加入错题本并显示正确选项和解析。

退出答题页时，本轮练习自动交卷，不在主页保留“继续练习”入口。已经提交的题目保持原有记录，尚未作答的题目不会被判错，之后仍可通过普通模式重新抽取。

两个应用默认共用以下数据库：

```text
~/Library/Application Support/医学综合练习/question-bank.sqlite3
```

## 文档输出

每日整理生成：

- `医学综合错题本_纯题.docx`
- `医学综合错题本_答案与解析.docx`
- `医学综合错题本_薄弱知识点.docx`

所有截图都按需要复习的内容处理，不根据页面显示的答对或答错状态过滤。程序只根据截图中实际存在的题干、选项、答案和解析整理内容；无法可靠识别的信息会标记为待校对。

## 构建 macOS 应用

环境要求：

- macOS 13 或更高版本
- Xcode Command Line Tools
- Swift 5.9 或更高版本

仅构建：

```bash
./script/build_and_run.sh --build-only
```

构建后的应用位于 `dist/`。构建并启动两个应用：

```bash
./script/build_and_run.sh
```

安装到 `/Applications` 并验证进程：

```bash
./script/build_and_run.sh --install-verify
```

运行测试：

```bash
swift test
```

## macOS 权限

首次使用全局快捷键时，需要在“系统设置 → 隐私与安全性 → 辅助功能”中授权。首次截图时还需要允许“屏幕与系统音频录制”。授权后请退出并重新打开应用。

每日整理使用当前用户的 LaunchAgent 执行，设置窗口无需保持打开。

## 隐私

应用不读取浏览器账号、密码、Cookie 或网页接口，不上传截图、题库和作答记录。仓库中也不包含用户截图、本地数据库、生成的 Word 文档或已编译应用。
